# Digital Wellbeing

A simple desktop application designed to encourage more mindful use of apps and support everyday focus.

This project is being shared so that survey participants can download the application, try its features, and provide feedback.

## Download

1. Open this GitHub repository.
2. Select **Releases**.
3. Open the latest release.
4. Download the ZIP file attached to that release.
5. Save the ZIP file to your computer.

> Download the application only from this project's official GitHub repository and its Releases page.

## Installation

The application is distributed as a ZIP file. You do not need to install Python or Kivy to run this packaged version.

1. Find the downloaded ZIP file.
2. Right-click it and select **Extract All...**.
3. Choose a location and select **Extract**.
4. Open the extracted folder.
5. Keep the application files together. Do not move the `.exe` file out of its folder or delete the `_internal` folder.

The extracted folder should contain files similar to these:

```text
Digital Wellbeing App/
├── digital wellbeing app.exe
└── _internal/
    └── (application support files)
```

The exact contents inside `_internal` may vary. Keep the complete folder as downloaded.

## How to start the application

1. Open the extracted **Digital Wellbeing App** folder.
2. Double-click `digital wellbeing app.exe`.
3. Wait a few moments for the application to start.

The first launch may take a little longer than later launches.

## Windows security warning

Windows may show a **Microsoft Defender SmartScreen** message such as **Windows protected your PC** when you first open the application.

This warning can appear when an application is not signed with a code-signing certificate that Windows recognizes, or when Windows does not yet have enough reputation information about it. It does not, by itself, prove that a file is safe or unsafe.

Only continue if you intentionally downloaded the ZIP from this project's official GitHub Releases page and are comfortable trusting that source.

If you choose to continue:

1. Check that you downloaded the file from the official project repository.
2. On the SmartScreen message, select **More info**.
3. Check the displayed application details.
4. If you trust the source, select **Run anyway**.

If you are unsure, do not run the application. Ask the project owner or your survey contact for help. You can also scan the downloaded ZIP or extracted files with your security software before opening the application.

## What is included?

The project is a digital wellbeing application. Its intended purpose is to help users manage time spent on selected apps and encourage focus through short activities.

The application includes these areas:

- **App time limits:** set time limits for selected apps within the application.
- **Time-up screen:** appears when the set time is used.
- **Focus activities:** activities are available in visual, reading, and mathematics categories.
- **XP and extra time:** activities can award XP, which can be used in the in-app shop for additional app time.
- **Profile:** a user profile area with a customizable profile colour.

Some app-use behaviour may be simulated by this version rather than controlling or blocking other applications on the computer. Please use the application as presented and report anything that is unclear or does not work as expected.

## Troubleshooting

### The application does not open

- Make sure you extracted the ZIP file first.
- Open the EXE from inside the extracted folder.
- Check that the `_internal` folder is still beside the EXE.
- Do not run the EXE directly from inside the ZIP preview.
- If Windows displays a security warning, read the **Windows security warning** section above.

### An error mentions `python313.dll` or a missing DLL

This usually means that the application cannot find one of its required support files.

- Extract the complete ZIP again.
- Make sure the EXE and `_internal` folder are in the same application folder.
- Do not send, copy, or run only the EXE file.

### The application closes or shows another error

Please note the error message or take a screenshot, then contact the project owner or your survey contact. Include your Windows version if you know it.
